// 01HuskyHack 2026

Anchor

Scam and account-takeover defense for credit unions

Built with Yohannes Kassa for Sound Credit Union and UW Tacoma's hackathon. Pause & Reflect holds payments that break a member's own pattern, asks questions that expose the scam script, returns an explainable risk score and can alert a trusted family member, while the member keeps the final say. Takeover Lockdown cuts digital access off from money movement, re-verifies identity outside the fraudster's reach and moves funds to a new account.

  • React
  • TypeScript
  • Express
  • Supabase
  • Azure OpenAI
// 02In design

Natural World in Numbers

Measure anything with a camera · working name Lik (ልክ)

Point a camera, or type a name, and get length, height, volume, surface area and estimated weight. Every number carries an error bar and a tag: measured, estimated or referenced. One engine ships three ways: an iOS app, a metered API and a drone edge SDK. First market: tree and vegetation measurement.

  • iOS · LiDAR
  • Computer vision
  • .NET API
  • Python GPU
  • Drone SDK
// 03Deployed

LimeGate

Multi-provider LLM inference gateway

Routes LLM traffic to AWS Bedrock with Azure fallback behind a reliability layer: Lua-based token-bucket rate limiting, circuit breakers, PII redaction and cost attribution. Ships with SLOs and burn-rate alerts, runbooks, Argo canary deploys, a typed SDK, k6 load tests and Grafana dashboards.

  • AWS EKS
  • ElastiCache
  • Bedrock
  • Azure
  • Argo
// 04Deployed

LabelCheck

AI label compliance verification

A vision model reads an alcohol label into structured fields, and a deterministic rules engine decides Pass, Needs review or Fail. It matches brand names leniently, cross-checks ABV against proof, normalizes volumes across units and checks the federal health warning word for word. Handles single labels or CSV and ZIP batches, backed by 26 tests.

  • ASP.NET Core 8
  • React
  • TypeScript
  • Vision LLM
  • Azure App Service
// 05v1 built

Farm AI

Multi-tenant drone analytics SaaS

Turns drone flights into field intelligence: NDVI, GNDVI and SAVI vegetation maps, YOLOv8 object detection, and weather and soil data from OpenWeatherMap, SoilGrids and NASA POWER. Postgres row-level security isolates each tenant, and a plugin architecture adds new industries without schema changes. Version 1 covers agriculture and energy.

  • FastAPI
  • PostGIS
  • YOLOv8
  • React
  • Docker

Engineering standards

every product, every time
Security

Authentication, password hashing, rate limiting, CSRF protection, input validation and audit logs.

Reliability

Retries, idempotent operations and graceful failure, informed by years of on-call at Microsoft.

Performance

Indexing, caching and pagination designed in from the schema up.

Observability

Structured logging and metrics, so problems show up on a dashboard before they show up in a support ticket.

Testing

Automated tests alongside the code they cover, run in CI on every change.

Documentation

Architecture, API design, schema and deployment notes, with diagrams, handed over with the code.
